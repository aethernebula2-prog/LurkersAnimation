Animation Setup
Body 7×10 · Arms 2×4 each · Feet 3×3 each. Limbs rotate around their pivots; customize the layer order below.

1. Select a Body Part

Selected Part Properties

Position X/Y support two decimal places. Set Pivot X/Y independently. For the body, position is its top-left corner; for limbs, it is the default top-edge center.

Animation Parameters

Amplitude controls swing range; frequency controls cycles per second; phase offsets motion relative to other parts.

Draw Selected Part

Select a part, then draw on the pixel canvas below. Transparent pixels remain transparent. Rotation uses the configured pivot point.
HEX and RGB values stay in sync, so you do not need to reopen the color picker.
100%
Alpha 0% = fully transparent; 100% = fully opaque. New pixels retain their own opacity.

Layer order can be customized below. Each part has independent pivot, angle, amplitude, frequency, phase, and color settings.

2. Canvas & Preview

Scene & Character

Drag a visible body part to move it. Drag an empty/background area to reposition the background. Use the size controls to scale either one. Background and character are combined in exports.

Export

Editing Tips

Coordinates are measured in grid cells. Position and pivot values support two decimal places. Each part has independent Pivot X/Y; limbs default to the top-edge center and the body to its top-left corner. The body does not swing. Positive angles rotate clockwise. Face Left mirrors the full composition.

GIF export generates frames across the loop duration. Limb motion is calculated from the current parameters.
